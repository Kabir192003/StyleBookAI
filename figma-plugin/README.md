# StyleBook Import (Figma plugin)

Redeems a code generated by StyleBook's Studio → Export drawer → "Figma
Components" panel, and builds real Auto Layout frames/components bound to a
Figma Variable Collection from it. See `lib/figmaExport/` in the main repo
for the payload this plugin consumes.

## Setup

```bash
npm install
npm run build
```

Then in Figma: **Plugins → Development → Import plugin from manifest…**,
point it at `manifest.json` in this directory.

Before shipping, replace `YOUR-STYLEBOOK-DOMAIN` in `manifest.json`'s
`networkAccess.allowedDomains` with the real deployed StyleBook origin.

## Status

V1 scope: this has been written against the documented Figma Plugin API
(Auto Layout frame creation, Variables, `createNodeFromSvg`,
`combineAsVariants`) but has not been run inside Figma itself yet — that
requires the Figma desktop/web app, which isn't available in this
environment. Before relying on it, load it as a dev plugin (above) and walk
through an actual import against a code generated by a running StyleBook
instance; fix up any API signature drift against the current
`developers.figma.com/docs/plugins` docs as needed.
