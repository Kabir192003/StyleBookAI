## Name
StyleBook Import

## Tagline
Import a StyleBook design system as real, editable Figma frames.

## Description
Paste a code from StyleBook's Studio → Export drawer → "Figma Components"
panel, and this plugin builds it out as real Figma frames — not a flat token
file you have to reconnect by hand.

What you get:
- The current Studio canvas, rebuilt as an Auto Layout frame
- A component library — buttons, cards, inputs, and more — as a Figma
  component set with hover, active, disabled, and focus variants
- Colours and type sizes bound to a real Figma Variable Collection, with
  light and dark wired up as swappable themes

Get a code from any project at style-book-ai.vercel.app — no account needed
to view the exported result, just to build the project in Studio first.
